Trust & Compliance

Privacy Policy & Security Standards

Goodlife Bulk Enrollor is engineered with strict zero-telemetry local browser isolation.

Last Updated: August 1, 2026

1. Data Collection & Privacy Isolation

Goodlife Bulk Enrollor ("the Extension") operates 100% locally inside the user's Google Chrome browser environment. The Extension does NOT collect, transmit, store, or share any personal, customer, or dealership data on external servers or third-party analytical services.

2. Local Data Processing

All vehicle identification numbers (VINs), customer names, contact numbers, and CSV uploaded records remain strictly within Chrome's isolated chrome.storage.local browser environment on the user's machine. This data is utilized solely for form autofill automation on the designated portal.

3. Permission Disclosures

  • activeTab & scripting: Used exclusively to interact with DOM form elements on hmclgoodlife.heromotocorp.biz/GoodlifeDLWeb/#/login.
  • sidePanel: Used to display the user dashboard interface within Chrome's native side panel.
  • storage: Stores user automation preferences and local device license state.
  • notifications & alarms: Triggers desktop alerts upon batch task completion.

4. Security & Cryptography

Device license activation uses local AES-256-CBC Web Crypto hardware fingerprint verification. No remote authentication server is contacted during operation.

5. Contact Information

For privacy inquiries or technical support, contact CalcLabz at support@calclabz.com.

Questions & Answers

Frequently Asked Questions

How do I install the extension from Chrome Web Store?
Click the "Add to Chrome" button at the top to open our official Chrome Web Store page, then click "Add to Chrome" and confirm permissions.
Does this tool work for both Joyride and GoodLife?
Yes! Goodlife Bulk Enrollor features a one-click tab switcher that toggles between Joyride Online Enrollment and GoodLife Enrolment forms.
How do I obtain an offline License Key for my PC?
Open the extension side panel, copy your unique Device ID displayed on the screen, and send it to support@calclabz.com to get your license key.
What happens if my internet connection disconnects mid-batch?
The extension's Auto-Resilience engine automatically detects internet loss, safely pauses the queue, and resumes right from the last processed VIN once connectivity returns.
